# TCC Precisão Laser - TCC

## Tema provisório
Sistema web integrado para gestão de pedidos, estoque e entregas em pequenos negócios.

## Integrantes
- Alander Vieira Andrade (alandervieiraandrade-ui)

## Objetivo
Desenvolver um sistema que registre pedidos, controle o estoque, organize a fila de atendimento, calcule valores dos itens e acompanhe as entregas, reduzindo erros e retrabalho no dia a dia do negócio.

## Módulos previstos
- Cadastro de itens e preços
- Cálculo de valores
- Controle de estoque
- Fila de pedidos
- Gestão de entregas

## Status
Em planejamento (tema provisório).
